\# Master Character v1.0



\## Identity



This is the permanent avatar.



Never redesign him.



Every future illustration must represent exactly the same character.



\## Reference



Always use \*\*Master\_Character\_v1.0.png\*\* as the visual reference.



Never invent facial features.



Never modify facial proportions.



\## Style



Simple flat 2D vector illustration.



Corporate mascot style.



SVG-style artwork.



Transparent PNG.



Black outlines.



Solid colors.



No gradients.



No textures.



No realistic lighting.



No 3D.



\## Appearance



Keep exactly the same:



\- Face

\- Hair

\- Glasses

\- Body proportions

\- Slight abdomen

\- Clothing

\- Shoes

\- Smartwatch



\## Allowed changes



Only change:



\- Pose

\- Facial expression

\- Hand gestures

\- Camera angle

\- Temporary props



Everything else must remain identical.
